SEED DESTINY ONLINE 0.4.0

1. GAME FILES
Open Game & graphics. Select your original NM00034 disc ISO and dongle BIN.
No separate BIOS is needed. Save. Enhanced uses the separate 3x game window;
the observed flashing and black scenery defects are fixed on the tested PC. Original Vulkan is also available.

2. PLAY SOLO
Choose Play solo to start the original arcade mode without a room. First use
prepares its own cabinet automatically. Backspace adds credit; Enter starts.

3. CONTROLS
Connect your controller. Controls offers Xbox/keyboard presets and a live
XInput tester. Presets apply at next launch and back up existing mappings.
For custom/DirectInput mapping open F1 in Enhanced mode, select Pad1, double-
click a row, hold the desired input for three seconds, then Apply and OK.
Arrows move; Z shoots, X performs melee/confirms, S jumps/boosts, A changes target. Alt+Enter toggles
fullscreen; Escape returns to a window. See Controls.txt.

4. JOIN A FRIEND
In Playroom, paste the complete invitation, enter your name and passcode,
then Join & launch. Check connection tests server access without joining.
Wait for all four games to link. Preferred teams are coordination only:
choose the actual teams in the original game. Ready/start are lobby signals.

5. HOST
In Host on this PC, enter your reachable address and port 7443. Start the
server, then create a private room. Share the invitation and passcode privately.
Forward TCP 7443 and allow this launcher in Windows Firewall. Keep your host
running. Installation changes no router, firewall or VPN settings.

Server round-trip measurements do not prove game latency. A complete match
across separate Internet PCs still needs qualification; see InternetTest.txt.
Original game files are excluded. Corresponding sources and notices are
included. Uninstall preserves settings and saves.
