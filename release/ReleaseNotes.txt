SEED Destiny Online 0.3.3 - experimental release

Enhanced 3x graphics now uses a separate game window. The user confirmed this
display method is stable on the tested RTX 5090 PC after the embedded window
continued flickering with display synchronization alone. Synchronization stays
enabled. Missing scenery is a separate unresolved issue.

Normal arcade launches start automatically instead of waiting in a paused state.
F1 opens controller settings; Alt+Enter toggles fullscreen; Escape restores a
window; Ctrl+R pauses/resumes. Closing the game shuts down rendering first.
The launcher rejects older Enhanced runtimes without the separate-window fix.

Validation on the development PC: normal game startup and advancing attract
screens, controller dialog, fullscreen/windowed transitions and window close.
All 27 automated launcher/transport tests passed. The packaged self-test covers
four-client encrypted room transport, not game rendering or Internet gameplay.

Earlier qualification with 0.3.0 completed a local four-cabinet timed 2-on-2
round with normal results, 136,443 frames sent and 409,329 deliveries. That
complete round has not been repeated with 0.3.3. Public-address TLS connectivity
has passed on the host, but a full match between separate Internet PCs remains
unverified, as do other GPUs, clean-machine setup and gameplay reconnects.

The original disc ISO and dongle BIN are supplied by each player. No separate
BIOS is required. Original game data and saved states are excluded. Patched
emulator, launcher and dependency sources and notices are included.
